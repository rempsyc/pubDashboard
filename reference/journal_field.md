# List of academic journals and corresponding fields

List of academic journals and corresponding fields

## Usage

``` r
journal_field
```

## Format

A data frame with 60 rows and 5 variables:

- journal:

  academic journal

- journal_abbr:

  abbreviation of the journal name

- openalex_id:

  the OpenAlex ID

- field:

  the field of research

- original_journal:

  Whether it is part of one of the six original journals
