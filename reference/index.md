# Package index

## All functions

- [`add_region()`](https://rempsyc.github.io/pubDashboard/reference/add_region.md)
  : Add regions to pubDashboard dataframe

- [`clean_journals_continents()`](https://rempsyc.github.io/pubDashboard/reference/clean_journals_continents.md)
  : Clean dataframe, for names of journals and continents

- [`countries`](https://rempsyc.github.io/pubDashboard/reference/countries.md)
  :

  List of countries taken from the package `countrycode`

- [`detect_missing_journals()`](https://rempsyc.github.io/pubDashboard/reference/detect_missing_journals.md)
  : Detect missing journals

- [`dygraph_year()`](https://rempsyc.github.io/pubDashboard/reference/dygraph_year.md)
  : Generate a dygraph of journal paper percentages, by country and year

- [`fetch_openalex_pubs()`](https://rempsyc.github.io/pubDashboard/reference/fetch_openalex_pubs.md)
  :

  Downloads relevant publication data using `openalexR`

- [`get_journal_id()`](https://rempsyc.github.io/pubDashboard/reference/get_journal_id.md)
  :

  Extract `openalexR` journal ID from journal names

- [`journal_field`](https://rempsyc.github.io/pubDashboard/reference/journal_field.md)
  : List of academic journals and corresponding fields

- [`lapply_fetch_openalex_pubs()`](https://rempsyc.github.io/pubDashboard/reference/lapply_fetch_openalex_pubs.md)

  Loop `fetch_openalex_pubs` over journals or years
